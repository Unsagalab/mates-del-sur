# 🧉 Mates del Sur

Proyecto web desarrollado como práctica de Backend con Python, Flask y SQLite.

## Descripción

Mates del Sur es una tienda ficticia de mates y accesorios.

## Vista del proyecto

![Vista de Mates del Sur](Mates%20del%20Sur_%20tradici%C3%B3n%20en%20cada%20sorbo.jpg)


El proyecto incluye:

- Página principal con productos.
- Formulario de contacto.
- Guardado de consultas en una base de datos SQLite.
- Página para visualizar las consultas recibidas.

## Funcionamiento

El formulario de contacto envía los datos al backend desarrollado con Flask.

Python procesa la información y la guarda en una base de datos SQLite.

Después, las consultas pueden visualizarse desde una ruta administrativa.

```text
HTML / CSS
    ↓
Flask
    ↓
Python
    ↓
SQLite
